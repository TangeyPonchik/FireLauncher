# 🔥 FireLauncher

Современный, легкий и быстрый лаунчер для Minecraft (Java Edition) с открытым исходным кодом.

## ✨ Возможности
- 🚀 Поддержка всех версий Minecraft (включая снапшоты).
- 🛡 Интеграция с Ely.by (вход по аккаунту, смена скинов).
- 🧩 Установка Forge и Fabric в один клик.
- 🔍 Встроенный поиск и скачивание модов (через зеркало Modrinth).
- 🎨 Смена скина прямо в лаунчере.
- 📦 Импорт готовых сборок (.mrpack и .zip).
- 📊 Мониторинг ОЗУ и CPU.
- ⚙️ Гибкая настройка JVM-аргументов и выделяемой памяти.

## 📥 Как установить (для пользователей)
1. Перейди в раздел **Releases**.
2. Скачай `FireLauncher.exe`.
3. Положи `authlib-injector.jar` в ту же папку, где лежит `.exe`.
4. Запускай и играй!

## 💻 Как запустить из исходников (для разработчиков)
```bash
pip install customtkinter requests minecraft-launcher-lib psutil Pillow
python fire_launcher.py
